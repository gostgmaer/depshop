# Browser compatibility

**What was actually tested:** Chromium only (Playwright), at desktop 1280 px and an Android phone profile (Pixel, 412 px, touch). **No real phone, Safari, Firefox or Edge was tested** for this phase. The platform notes below describe how each browser is _documented_ to behave; each row must be confirmed by the manual checks in [mobile-testing.md](mobile-testing.md) before claiming support.

| Capability                           | Chromium (Chrome, Edge) desktop          | Android Chrome    | Android Firefox                                                  | iOS / iPadOS Safari                                              | Desktop Firefox            | Desktop Safari                                        |
| ------------------------------------ | ---------------------------------------- | ----------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------- | ----------------------------------------------------- |
| Responsive layout, bottom navigation | Tested (emulated)                        | Tested (emulated) | Expected                                                         | Expected                                                         | Expected                   | Expected                                              |
| Manifest, theme colour               | Tested                                   | Tested (emulated) | Expected                                                         | Partial: Safari uses the Apple tags in `<head>`                  | Manifest mostly unused     | Partial                                               |
| Install                              | `beforeinstallprompt` → "Install" button | Same              | Browser menu ("Install" / "Add to Home screen"); no prompt event | **Manual only:** Share → Add to Home Screen (instructions shown) | Not offered by the browser | Recent versions: File → Add to Dock (no prompt event) |
| Service worker, offline page         | Tested                                   | Tested (emulated) | Expected                                                         | Expected (supported)                                             | Expected                   | Expected                                              |
| Web Push                             | Supported                                | Supported         | Supported                                                        | **Only when added to the Home Screen** (iOS 16.4+)               | Supported                  | Supported (recent versions)                           |
| Shortcuts (long-press icon)          | Supported                                | Supported         | —                                                                | Not supported                                                    | —                          | —                                                     |

**Fallbacks:** the install card always shows a path that works (button, manual steps, or "use it in a tab"). Where push isn't available, Settings says so and alerts continue in-app and by e-mail.
