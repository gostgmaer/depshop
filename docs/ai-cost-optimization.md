# AI cost optimization

**Status 2026-11-18: no LLM cost has been incurred or measured.** No LLM account exists. Every test uses the deterministic `rules` extractor or a mocked LLM, which report zero tokens. Nothing below claims a saving.

## Where the LLM is used (by design, only two places)

| Stage               | Call                                                                                       | Can be skipped                                                    |
| ------------------- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| `intent_extractor`  | One structured-output call: query → `ExtractedIntent`, Pydantic-validated, bounded retries | No (today)                                                        |
| `generate_response` | One narration call over **computed facts**; output rejected if it adds numbers or URLs     | Yes: `narration` can be disabled; a deterministic summary is used |

Discounts, matching, ranking and price history are deterministic TypeScript and are never sent to the model.

## What is already measured and controlled

| Requested                       | Status                                                                                                                                                                                                                                                                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tokens per search               | Instrumented: `AgentRun.inputTokens/outputTokens`, per stage in `executionMetadata.tokens`                                                                                                                                                                                                                                  |
| Cost per search, cost per model | Instrumented as an **estimate**: Admin → AI models multiplies tokens by admin-entered list prices (`inputPaisePerMillionTokens`, `outputPaisePerMillionTokens`)                                                                                                                                                             |
| Monthly budget                  | `AiModelConfig.monthlyTokenLimit`. When `limitReached` (or the model is disabled), the agent switches to the **deterministic rules extractor**, with no LLM calls, until the next month (`providers/configurable.py`). The rules parser's quality therefore matters in production: 95 % holdout exact match after Prompt 24 |
| Model per purpose, fallback     | `AiModelConfig.provider/model/fallbackProvider/fallbackModel` (fallback only when configured)                                                                                                                                                                                                                               |
| Retries                         | Bounded (`LLM_MAX_RETRIES`); `intent_attempts` recorded per run                                                                                                                                                                                                                                                             |
| Failed executions               | `dealmind_agent_runs_15m{status}`                                                                                                                                                                                                                                                                                           |
| Model latency                   | Agent run duration (`dealmind_agent_run_duration_ms_15m`); **not split per LLM call**                                                                                                                                                                                                                                       |
| Cache hit rate                  | **Not applicable:** no LLM response cache exists (see below)                                                                                                                                                                                                                                                                |
| Quality per model               | **New:** `app.evals.intent_eval --provider configured` scores any configured model on the labelled query set ([search-quality-evaluation.md](search-quality-evaluation.md))                                                                                                                                                 |

## Candidate optimizations, and the evidence each needs before building

| Optimization                                                                                          | Expected effect                                          | Prerequisite measurement                                                                                                                                                                                             | Status                                      |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| **Deterministic parsing for simple queries:** skip the intent call when the rules parser is confident | Saves the larger of the two calls on simple queries      | The LLM's accuracy on the same 60-case set **and** the rules parser's accuracy on _real_ simple queries. The rules parser now scores 95 % exact on the holdout, but on queries written by the engineer, not shoppers | **RECOMMENDED**; BLOCKED on an LLM baseline |
| Disable narration for searches with few results                                                       | Saves the second call                                    | Users' use of the narrative (no signal collected yet)                                                                                                                                                                | RECOMMENDED                                 |
| Cache intent by normalised query                                                                      | Repeat queries ("best phone under 20000") skip the model | Repeat-query rate from k-anonymous popular-query analytics. The cache must be keyed only on the query text, never shared with user context (stated banks or memberships are per-user)                                | RECOMMENDED                                 |
| Smaller model for intent extraction                                                                   | Lower cost per token                                     | Per-model eval on the labelled set                                                                                                                                                                                   | RECOMMENDED                                 |
| Prompt trimming                                                                                       | Fewer input tokens                                       | Token counts per stage from production                                                                                                                                                                               | RECOMMENDED                                 |

**Rule for all of them:** no change ships if it lowers the holdout exact-match score on the labelled set, unless that's an explicit product decision ([search-quality-evaluation.md](search-quality-evaluation.md)).
